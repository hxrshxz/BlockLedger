# Project Screenshots

Important screenshots of the BlockLedger prototype.

## Current screenshots

- `01-landing.png` — landing page

## Naming convention

Use zero-padded, descriptive names:

- `01-landing.png`
- `02-dashboard.png`
- `03-identity.png`

Do not upload screenshots containing API keys, wallet seed phrases, tokens or other sensitive information.

## Adding screenshots to README

Reference them from the main `README.md` with a relative path:

```md
![BlockLedger dashboard](assets/screenshots/02-dashboard.png)
```
